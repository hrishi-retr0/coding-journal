## Variables

- Variables are containers that are used to store information or data.

- Naming convention for python is snake_case.


### Data Types


#### Strings

```python

first_name = "hrishi"
fav_food = "Pizza"
email = "hrishi@gmail.com"

print(first_name)
#prints hrishi

#To print the variable value along with some text we can use f-string (formatted string literals)

print(f"Hello {first_name}")
#prints Hello hrishi

print(f"Your email is {email}")
#prints Your email is hrishi@gmail.com

```

#### Integers

```python

age = 20
quantity = 4

print(f"You are {age} years old")
print(f"You have {quantity} apples")

```

#### Floats

```python
price = 11.99
gpa = 3.9

print(f"The price of the oil is ${price}")

```

#### Boolean

```python

is_student = True
for_sale = False

print(f"Are you a student?: {is_student}")

```


- Use the `type()` function to check a variable's data type: print(type(price))



## Type Casting

 - The process of converting a variable from one data type to another i.e str(), int(), float(), bool()


 ## Input/Output (I/O)

- Output with `print()`: Displays information to terminal.

Example: `print(f"Your age is {age}")`


- Input with `input()`: Prompts the user for text input.

Crucially, input() always returns a string. So, to perform any arithmetic operations, you would need to type cast it.
