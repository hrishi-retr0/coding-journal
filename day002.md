
## Type Casting

 - The process of converting a variable from one data type to another i.e str(), int(), float(), bool()


 ## Input/Output (I/O)

- Output with `print()`: Displays information to terminal.

Example: `print(f"Your age is {age}")`


- Input with `input()`: Prompts the user for text input.

Crucially, input() always returns a string. So, to perform any arithmetic operations, you would need to type cast it.

1. Difference between an integer and a string.
Answer. Integers are whole numbers which  can be used for mathematical calculations whereas a string is a character value represented in quotes.

2. Why was type casting necessary for the calculator?
Answer. Type casting was necessary for the calculator because the input() function always returns a string and it is not possible to perform arithmetic operations with a string.

3. What did you learn about f-string?
Answer. F - string (formatted string literal) lets us format selected parts of a string by letting us embed variables/expressions directly inside string literals.
