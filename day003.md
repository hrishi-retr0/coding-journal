## Control Flow - Decision making


### Conditional logic with if, elif and else:

This is how the program makes decisions.

#### 1. if

- Starting point of a conditional statement

- It checks a condition, and if the condition is `True`, then its block of code runs.

```python

x = 10

if x > 5:
    print("x is greater than 5")

```


#### 2. elif (short for else if)

- comes after an `if` or another `elif`.
- It lets you check another condition only if all previous conditions were False.

```python
x = 3

if x > 5:
    print("greater than 5")
elif x > 2:
    print("greater than 2")
```

##### Key Differences:

- if starts the condition chain.
- elif extends the chain with additional conditions.
- Python evaluates them **top to bottom**, and **stops at the first True condition.**

##### When to use Each:

- Use if when making the first check
- Use elif when you have **multiple mutually exclusive conditions** (only one should run)

#### 3. else

- Comes at the end (optional).
- Runs if none of the above conditions were true.
- Does not have a condition

```python
x = 1

if x > 5:
    print("greater than 5")
elif x > 2:
    print("greater than 2")
else:
    print("2 or less")
```


### Rule of thumb

- Use if/elif/else when only one outcome should happen
- Use multiple ifs when multiple outcomes can happen
