##Update:

- While trying to push the code above, I came across a few issues because of the new setup. First, I was asked to authenticate myself when I tried to push the changes. On entering my username and password, I was told that "Password authentication is not supported for Git operations". That is because it has been discontinued since 2021 due to security risks. Instead, I created a Personal Acess Token (PAT) which is safer as it can be revoked anytime, has an expiration date and has limited permissions. Also, I had autosave "on" on my main device so because of that habit I tried to push the changes but it wasn't showing up on my remote repo, so after some time I realized that and fixed it so the changes finally showed up.
